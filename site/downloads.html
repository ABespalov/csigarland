Downloads

Releases

Ready to download: the firmware, as an update file, and the utility, from the project's GitHub Releases, newest first, each with the day it was released and its release notes. The update file is signed under the project's root, which a garland running a release trusts: a garland you built with keys of your own takes only what you sign yourself.

Installing

Firmware

On the garland's portal, open Firmware and choose the .ota file. Or, in the utility, open Firmware and choose From the catalog: it downloads the release and checks it against this site's list. The garland checks the signature before it writes a byte, tries the new firmware for a minute, and goes back if it does not confirm itself.

The utility

One file for Windows, with nothing to install: download it and run it. It finds garlands on your network and pairs with yours by a press on its buttons. Linux and macOS are to follow.

Checking what you downloaded

Each file's SHA-256 is beside it here, and in the release's .manifest.json. To show a file is what its sources make, build it again from a clean fork: Building a Release Again, to the Byte. The firmware is compared by its image and effects pack, which needs no key, and the utility file by file.
