Загрузки

Релизы

Готовые файлы из GitHub Releases проекта (сначала самые новые): подписанный пакет обновления прошивки и эффектов, а также настольная утилита. Пакет обновления подписан корневым ключом проекта, которому доверяет релизная прошивка. Если вы собрали и впервые прошили плату со своими ключами, она принимает только обновления, подписанные вами.

Установка

Прошивка

В веб-портале гирлянды откройте вкладку Firmware и выберите скачанный файл .ota. Либо в настольной утилите откройте Firmware и нажмите «From the catalog»: утилита сама скачает релиз и сверит его хеш со списком. Гирлянда проверит цифровую подпись до записи во flash, запустит новую версию в пробном режиме на минуту и вернётся к старой при сбое.

Настольная утилита

Один исполняемый файл для Windows или Linux без установщика: скачайте и запустите, а в Linux сначала разрешите запуск — командой chmod +x или в свойствах файла. Утилита сама находит гирлянды в локальной сети и привязывается к вашему устройству после подтверждения кнопками на корпусе. Файл для Linux рассчитан на x86-64 с рабочим столом, Ubuntu 22.04 и новее. Версия для macOS запланирована.

Проверка скачанных файлов

Контрольная сумма SHA-256 указана рядом с каждым файлом и в файле .manifest.json релиза. Чтобы лично убедиться, что бинарный файл до байта соответствует открытому исходному коду, пересоберите его в чистом форке по инструкции Воспроизводимая сборка релиза до байта (Building a Release Again). Прошивка сверяется по бинарному образу и пакету эффектов (ключ подписи для этого не нужен), а утилита — побайтово целиком.
